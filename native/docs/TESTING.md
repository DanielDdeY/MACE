# Pruebas del módulo nativo

Desde la raíz del repositorio ejecutar `native/scripts/build-native.ps1 -Configuration Release` y, para Debug, `native/scripts/build-native.ps1 -Configuration Debug`. El script detecta Visual Studio 2022/2026 y CMake 3.28+ mediante `vswhere`; usa carpetas de compilación por generador. No elimina ni mueve directorios existentes. También se puede usar `CMakePresets.json` desde `native/`.

CTest ejecuta `abi_layouts` (offsets antiguos/V2), `abi_exports` (carga por ruta de la DLL real y consulta ABI), `telemetry_v2` (contrato de métricas e inventario en el equipo) y `gpu_provider_dispatch` (selección de proveedores simulados). `scripts/verify-native.ps1` repite la prueba de exportaciones sobre la ruta de DLL indicada y ejecuta el ejemplo FFM con JDK 22. `scripts/package-native.ps1` llama a ambos sobre el artefacto que distribuye.

`hardware_probe.exe` es una prueba manual de CPUID/DXGI: identifica CPU y adaptadores sin pedir marcas al usuario. `test_mace.exe` se compila desde `test_main.c` y es la demostración manual para compañeros: consulta la API V2, muestra el modelo y las lecturas disponibles de CPU, enumera **cada** GPU física con nombre/fabricante/ID PCI/proveedor y muestra uso, temperatura, potencia, ventilador y memoria de vídeo. Una métrica ausente se imprime como `No disponible` con su motivo; no se interpreta un cero como lectura válida. La sección de procesos conserva la enumeración, filtro y primeras diez filas.

En Visual Studio, abrir la carpeta `native/`, escoger el preset de la versión instalada (`vs2022-x64` o `vs2026-x64`), seleccionar `test_mace.exe` como elemento de inicio y ejecutar con Ctrl+F5. Para Radeon, configurar `MACE_ADLX_SDK_DIR` con la raíz del SDK oficial ADLX antes de compilar; sin ese proveedor la GPU seguirá identificada por DXGI, pero sus sensores pueden decir `sin proveedor`. Las carpetas `build/vs2022-x64` y `build/vs2026-x64` son independientes. La demostración depende del hardware y no constituye una prueba automática de sensores. Las lecturas físicas Intel/AMD, APUs móviles y GPU de las tres marcas se registrarán en `HARDWARE_COMPATIBILITY.md` cuando existan los proveedores y equipos correspondientes.
