# Pruebas del módulo nativo

Desde la raíz del repositorio ejecutar `native/scripts/build-native.ps1 -Configuration Release` y, para Debug, `native/scripts/build-native.ps1 -Configuration Debug`. El script detecta Visual Studio 2022/2026 y CMake 3.28+ mediante `vswhere`; usa carpetas de compilación por generador. No elimina ni mueve directorios existentes. También se puede usar `CMakePresets.json` desde `native/`.

CTest ejecuta `abi_layouts` (offsets antiguos/V2), `abi_exports` (carga por ruta de la DLL real y consulta ABI), `telemetry_v2` (contrato de métricas e inventario en el equipo) y `gpu_provider_dispatch` (selección de proveedores simulados). `scripts/verify-native.ps1` repite la prueba de exportaciones sobre la ruta de DLL indicada y ejecuta el ejemplo FFM con JDK 22. `scripts/package-native.ps1` llama a ambos sobre el artefacto que distribuye.

La fase 3 añade `process_security` (filtros con rutas sintéticas y protección propia) y `process_api` (identidades, ruta completa, buffers y estados). La fase 4 añade `process_extensions` (muestras y estado de ventanas) y `blackbox_buffer` (anillo, sobrescrituras, lectura por copia, doble cierre y limpieza). La fase 5 añade `lifecycle` (once ciclos, reinicio de contadores y crecimiento después de carga inicial), `concurrency` (sondeos y apagados simultáneos) y `buffer_concurrency` (lectura/escritura mientras se cierra el mapeo). Para probar terminación real, usar `build-native.ps1 -EnableTerminationTest` en un directorio de compilación separado: `process_termination` solo crea y cierra `process_helper.exe`. Esta prueba está desactivada por defecto y nunca recibe PID de aplicaciones del usuario. Véase [PHASE5.md](PHASE5.md).

`hardware_probe.exe` es una prueba manual de CPUID/DXGI: identifica CPU y adaptadores sin pedir marcas al usuario. `test_mace.exe` se compila desde `test_main.c` y es la demostración manual para compañeros: consulta la API V2, muestra el modelo y las lecturas disponibles de CPU, enumera **cada** GPU física con nombre/fabricante/ID PCI/proveedor y muestra uso, temperatura, potencia, ventilador y memoria de vídeo. También presenta RAM total/disponible, enumera todos los procesos elegibles sin un límite fijo de 128, muestra las primeras diez filas con memoria y ruta completas (o todas con `--all-processes`) y explica el estado de cada métrica. La sección final lee Working Set/Private Bytes del propio ejecutable, verifica escritura y lectura en un anillo temporal y muestra el resultado de la consulta de ventanas. Una métrica ausente se imprime como `No disponible` con su motivo; no se interpreta un cero como lectura válida. Para repartirlo sin herramientas de compilación, el paquete incluye `bin/test_mace.exe` junto a `bin/mace_native.dll`. Véase la [guía paso a paso para el grupo](TEAM_DIAGNOSTIC_GUIDE.md).

En Visual Studio, abrir la carpeta `native/`, escoger el preset de la versión instalada (`vs2022-x64` o `vs2026-x64`), seleccionar `test_mace.exe` como elemento de inicio y ejecutar con Ctrl+F5. Para Radeon, configurar `MACE_ADLX_SDK_DIR` con la raíz del SDK oficial ADLX antes de compilar; sin ese proveedor la GPU seguirá identificada por DXGI, pero sus sensores pueden decir `sin proveedor`. Las carpetas `build/vs2022-x64` y `build/vs2026-x64` son independientes. La demostración depende del hardware y no constituye una prueba automática de sensores. Las lecturas físicas Intel, APUs móviles y GPU de las tres marcas se registrarán en `HARDWARE_COMPATIBILITY.md` conforme se prueben en esos equipos. En una sesión sin escritorio interactivo la respuesta de ventanas puede ser `ERROR` aunque las muestras de memoria funcionen.

Para temperatura de CPU AMD, configurar `MACE_RYZEN_SDK_DIR` con la raíz del **Ryzen Master Monitoring SDK** antes de generar CMake, o usar `build-native.ps1 -RyzenSdkDirectory <ruta>`. `test_mace.exe` debe ejecutarse como administrador para que el SDK acceda a su controlador. Si se ejecuta sin elevación, `ACCESS_DENIED` confirma la selección del proveedor, pero no valida el valor térmico. Véase [AMD_CPU_TEMPERATURE.md](AMD_CPU_TEMPERATURE.md).
