# Entrega para los otros desarrolladores

El paquete verificado se encuentra bajo `native/dist/mace-native-1.1.0-win-x64-.../`. Usar `bin/mace_native.dll` de ese paquete y cotejar su SHA-256 con `build-info.json` o `SHA256SUMS.txt`. El `.lib` sirve para consumidores C; Java FFM carga directamente la DLL. Los headers publicados son la fuente del contrato C.

El Java actual enlaza los siete símbolos anteriores. `CP_GetAbiInfo` es adicional y no obliga a modificar inmediatamente `app/`. Para pruebas en desarrollo se puede fijar `MACE_NATIVE_LIB` o `-Dmace.native.lib` a la ruta absoluta del binario de `dist/`; esto evita que el localizador prefiera una DLL antigua de `app/lib/`. El script `packaging/package-windows.bat` del repositorio compila y copia la DLL, pero todavía no consulta su ABI ni el manifiesto de hashes; Dev 3 deberá integrarlo antes de la entrega general.

Firma FFM de la nueva consulta: `int CP_GetAbiInfo(MaceAbiInfoV2* out_info, uint32_t out_capacity, uint32_t* out_required_size)`, descriptor `FunctionDescriptor.of(JAVA_INT, ADDRESS, JAVA_INT, ADDRESS)`. La llamada inicial `NULL, 0, &required` devuelve `-2` y `required=64`; después se reserva un segmento de 64 bytes alineado a 8 y se vuelve a llamar. El ejemplo ejecutable está en `examples/ffm/NativeContractProbe.java`. Comprobar `abi_major=1`, `abi_minor>=1`, tamaños 1584/28/16 y los bits de capacidad antes de consumir funciones futuras. No interpretar la versión de estructura 2 como soporte de todos los módulos V2.

Los registros antiguos no cambiaron, pero conservan los defectos conocidos: GPU Radeon/Intel no se lee todavía, temperatura/potencia AMD no están implementadas y el campo heredado de ventilador NVML contiene un porcentaje aunque su nombre diga RPM. Los nuevos proveedores, la seguridad de terminación y el cierre del mapping se abordarán en las fases 2–5. El paquete de fase 1 es una base identificable para integrar y probar; no debe presentarse como la telemetría final.
