MACE

Monitor de hardware y procesos para Windows

Muestra lecturas con su estado y permite gestionar programas de forma manual. La disponibilidad de sensores depende del equipo y sus proveedores; una lectura no disponible se muestra como N/D.

Qué mide y de qué depende

Las funciones están condicionadas a soporte y permisos. Preview utiliza datos simulados y no prueba los sensores físicos.

ComponenteLecturas previstasCondiciones
CPUUso, temperatura y potenciaUso mediante Windows. Sensores CPU mediante LHM, con elevación, PawnIO operativo y hardware compatible; de lo contrario N/D.
GPU NVIDIAMétricas que exponga el proveedorNVML del controlador y LHM como respaldo; no se garantiza cada sensor en cada modelo.
GPU AMD RadeonTemperatura, uso, memoria y otros sensores disponiblesLHM y controlador AMD; potencia con cobertura y ámbito limitados. No se afirma que toda lectura GPU requiera PawnIO/elevación.
GPU IntelMétricas disponibles del fabricanteIGCL y LHM como respaldo; cobertura física de la candidata nueva NO VERIFICADA.
Memoria y procesosRAM, lista de procesos y gestión manualAPIs de Windows, permisos y protecciones del sistema; no se garantiza acceso a todos los procesos.

Requisitos y paquete

Windows x64

Windows 10/11 de 64 bits. El launcher principal solicita administrador; el permiso por sí solo no garantiza sensores disponibles.

Aplicación completa

La app-image necesita su carpeta completa: launchers, runtime Java, DLL, helper autocontenido y dependencias. Un ejecutable aislado no basta.

PawnIO y Preview

El paquete de referencia incluye el setup oficial intacto; MACE no lo ejecuta por sí solo. El instalador Inno definitivo y su encadenamiento siguen pendientes. Preview no requiere sensores ni administrador.

El Micro-HUD está destinado al escritorio; superposición sobre videojuegos en pantalla completa NO VERIFICADA. La caja negra y las preferencias se guardan localmente, con retención limitada.

Un SHA-256 compara bytes; no sustituye la firma del editor, la revisión legal o las pruebas funcionales. No se anuncian aquí firmas ni hashes de un instalador nuevo todavía no construido.

Privacidad

MACE consulta hardware y procesos y conserva caja negra y preferencias localmente. La revisión estática del código propio no identificó un cliente que envíe automáticamente esas métricas a un servidor.

NO VERIFICADO: tráfico o diagnóstico indirecto del conjunto de runtimes, controladores, sistema y futuro instalador; no se ha realizado una captura exhaustiva. No se promete ausencia universal de red.

Antes de compartir informes, revisar perfiles, identidades locales, correos, SID, secretos y datos de máquina. Los modelos CPU/GPU y mediciones pueden compartirse según la decisión del mantenedor.
